# Лабораторная работа № 9. Многопоточность в Java

**ФИО автора:** Гуляева Арина Евгеньевна 

**Группа:** ФИТ-251

## Описание
Работа демонстрирует три подхода к многопоточности:
1. Создание потоков через `Thread` и `Runnable`.
2. Реализация паттерна Producer-Consumer с ручной синхронизацией (`wait`/`notifyAll`).
3. Реализация того же паттерна с использованием `ExecutorService` и `BlockingQueue`.

## Команды для сборки и запуска
1. Сборка проекта:
   `mvn clean package`
2. Запуск приложения:
   `java -jar target/java-lab9-1.0-SNAPSHOT.jar`
